## 🚀 Featured Project

### PathPilot AI — Robot Path-Planning Playground

A robotics seminar project focused on implementing and testing path-planning algorithms through a web interface.

**Current focus**
- Implementing and debugging A* and RRT path planning
- Testing start/goal validity and obstacle collision handling
- Checking whether a planned path is actually collision-free
- Connecting a Python FastAPI backend to a React frontend
- Improving the interface so algorithm behaviour is easier to understand and demonstrate

**Planned evaluation**
- Path success rate across different obstacle layouts
- Path length and planning time
- Collision-free path validation
- Behaviour in blocked or unreachable scenarios

> Project status: In development. Features and evaluation results will be added after they are tested.
